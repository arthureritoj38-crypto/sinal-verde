# Publicar o Sinal Verde no GitHub Pages

1. Crie um repositório chamado `sinal-verde`.
2. Carregue todo o conteúdo desta pasta, incluindo `.github`.
3. Confirme que a branch principal se chama `main`.
4. Abra **Settings → Pages** e seleccione **GitHub Actions**.
5. Abra **Actions** e aguarde o fluxo “Publicar no GitHub Pages”.
6. Copie o endereço publicado.
7. No Supabase, abra **Authentication → URL Configuration** e coloque:
   - **Site URL:** endereço publicado;
   - **Redirect URLs:** o mesmo endereço e o mesmo endereço seguido de `/**`.
8. Abra o site, crie a conta `arthureritoj38@gmail.com` e confirme o e-mail.
9. Depois, promova essa conta para administrador no Supabase.
